# Vehicle Analysis Dashboard

A Power BI dashboard project for analyzing vehicle-related data and presenting the results in an interactive report.

## Repository contents

- `vehicle analysis dashboard.pbit` - reusable Power BI template
- `vehicle analysis dashboard.pdf` - dashboard preview/documentation

## Open the dashboard

1. Install Microsoft Power BI Desktop.
2. Download `vehicle analysis dashboard.pbit`.
3. Open the template in Power BI Desktop.
4. Complete any requested data-source configuration when prompted.

## Preview

The PDF file in this repository provides a preview of the dashboard layout and report visuals.
